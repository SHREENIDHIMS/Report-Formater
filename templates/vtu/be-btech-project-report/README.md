# VTU B.E./B.Tech. Project Report — Research Draft

This package is a **source-attributed research draft**, not a verified universal VTU template. Check scheme/cohort and any college/department circular before using it for a student's final export.

Files:
- `manifest.yaml`: identity, scope, lifecycle and sources.
- `rules.yaml`: current machine-readable baseline and status of each rule.

Do not change `status` to `verified` without a human evidence review, scheme mapping, golden report tests and a recorded reviewer/date. Do not add font-family requirements without an applicable source.
