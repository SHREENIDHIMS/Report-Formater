# Research source register

**Research checked:** 25 November 2026. Links should be re-opened before publishing template claims or competitor pricing. Official instructions may change.

## VTU primary sources

1. **VTU Examination Guidelines — official page**  
   https://vtu.ac.in/en/examination-guidelines/  
   Relevant section: B.E./B.Tech. project report preparation guidelines. Used for A4 page, margins, line spacing, font sizes, heading alignment, abstract length, numbering, figures/tables and references.  
   Interpretation caution: this is a general guideline page. It does not by itself settle applicability for every scheme/cohort or local college rule.

2. **VTU-hosted Guidelines for the final year project work PDF**  
   https://vtu.ac.in/wp-content/uploads/2025/11/00.-Guidelines-for-Project-work-.pdf  
   Relevant portion: suggested project report flow, certificate/declaration and report structure guidance. PDF is hosted under a November 2025 upload path. Reconfirm document title, scheme and effective status before template publication.

3. **VTU B.E./B.Tech. Scheme and Syllabus page**  
   https://vtu.ac.in/en/b-e-b-tech-scheme-syllabus/  
   Used to note that more than one scheme appears on the official site and that final-year project guidance is linked in the scheme material. Must be checked again when mapping an individual cohort.

- VTU official sources are primary but still require cohort and college applicability confirmation.
- Competitor websites are first-party marketing pages; pricing/feature claims can change and are not independent product tests.
- Framework docs establish technical capabilities, not suitability for this exact architecture. Validate with a prototype and licensing review.
- Add new sources with access date, title, relevant section/page, what claim they support and any ambiguity.
